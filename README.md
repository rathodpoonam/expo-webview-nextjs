# Expo App

## Description
This Expo app wraps the deployed Next.js project using a WebView.

## How to Run

1. **Clone the repository:**
   ```bash
   `git remote add origin https://github.com/rathodpoonam/expo-webview-nextjs.git`

2. Install dependencies:
   npm install or npm i

3. Start the Expo app: `npx expo start or npm start`
